# DataOps Pipeline WebCraw

A Python-based data operations pipeline for web crawling and data processing.

## Overview

This project provides a comprehensive DataOps solution for web crawling, data extraction, and ETL pipeline orchestration. Built with Python and containerized using Docker, it enables scalable data collection and processing operations.

## Project Structure

```
DataOps_pipeline_WebCraw/
├── infra/          # Infrastructure and configuration files
├── src/            # Source code for the pipeline
└── docker/         # Docker configuration and containers
```

## Tech Stack

- **Language**: Python (99.7%)
- **Containerization**: Docker (0.3%)
- **Purpose**: Web crawling and data operations pipeline

## Features

- 🕷️ Web scraping and crawling capabilities
- 🔄 ETL pipeline orchestration
- 📦 Containerized deployment with Docker
- 🚀 Scalable data processing

## Getting Started

### Prerequisites

- Python 3.8+
- Docker (optional, for containerized deployment)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/HungphamLeo/DataOps_pipeline_WebCraw.git
cd DataOps_pipeline_WebCraw
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

### Usage

Refer to the individual module documentation in the `infra/` and `src/` directories for detailed usage instructions.
